# راه‌اندازی API مدیریت مقالات RLS

این راهنما برای شاخه `feature/d1-manuscript-admin` است. اجرای مراحل Cloudflare خارج از GitHub انجام می‌شود؛ تا پایان آزمایش، این قابلیت را فعال‌شده تلقی نکنید.

## ۱. پشتیبان‌گیری و اجرای مهاجرت D1

در Cloudflare Dashboard، به **Workers & Pages → D1 → rls-manuscripts → Console** بروید. ابتدا از پایگاه داده نسخه پشتیبان تهیه کنید. سپس محتوای فایل `workers/migrations/001_editorial_history.sql` را فقط یک‌بار اجرا کنید.

این فایل شامل `ALTER TABLE manuscripts ADD COLUMN editor_note TEXT` است و برای اجرای دوباره طراحی نشده است. اگر قبلاً اجرا شده، آن را دوباره اجرا نکنید.

## ۲. ایجاد Worker جداگانه

یک Worker جدید با نامی مانند `rls-manuscript-admin` ایجاد کنید و محتوای `workers/manuscript-admin.js` را در ویرایشگر آن قرار دهید. Worker ارسال مقاله فعلی را جایگزین یا ویرایش نکنید.

در بخش **Bindings**، اتصال D1 با نام متغیر `DB` را به پایگاه داده موجود `rls-manuscripts` اضافه کنید.

در **Settings → Variables and Secrets**، یک Secret با نام `ADMIN_TOKEN` بسازید. از یک مقدار تصادفی قوی استفاده کنید؛ آن را در کد، GitHub یا نشانی عمومی سایت قرار ندهید.

## ۳. مسیر API و پنل

پس از Deploy، دامنه Worker را یادداشت کنید. مسیرهای پشتیبانی‌شده:
- `GET /admin-api/manuscripts`
- `PATCH /admin-api/manuscripts/{id}`

در صفحه `admin/submissions.html`، نشانی کامل Worker را وارد کنید و مقدار `ADMIN_TOKEN` را در کادر رمز قرار دهید. رمز در این صفحه فقط در `sessionStorage` همان نشست مرورگر نگهداری می‌شود. از رایانه عمومی استفاده نکنید و پس از پایان کار نشست را ببندید.

## ۴. آزمایش ضروری پیش از استفاده واقعی

1. صفحه پنل را باز کنید و بررسی کنید فهرست مقالات دریافت شود.
2. یک مقاله آزمایشی را جست‌وجو کنید و جزئیات را باز کنید.
3. وضعیت را تغییر دهید و یک یادداشت آزمایشی ذخیره کنید.
4. صفحه را تازه‌سازی کنید و ماندگاری تغییر را بررسی کنید.
5. درخواست بدون توکن باید پاسخ 401 و درخواست از Origin غیرمجاز باید رد شود.
6. پس از آزمایش، هر مقاله آزمایشی را طبق رویه نگهداری داده‌ها پاک یا علامت‌گذاری کنید.

## محدودیت امنیتی فعلی

این نسخه از یک توکن مشترک استفاده می‌کند؛ حساب جداگانه برای هر سردبیر، MFA، ثبت نام کاربر، و رابط مشاهده تاریخچه تغییرات هنوز پیاده‌سازی نشده‌اند. پیش از استفاده گسترده، بهتر است دسترسی از طریق Cloudflare Access یا سازوکار هویت مستقل محدود شود.
