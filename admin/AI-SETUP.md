# RLS Admin AI service

این فایل برای راه‌اندازی یک‌باره ترجمه و استخراج هوشمند پنل مدیریت است.

## 1. Cloudflare Worker

فایل `admin/ai-worker.js` را به‌عنوان یک Cloudflare Worker ایجاد/Deploy کنید.

در Variables/Secrets این دو مقدار را تنظیم کنید:

- `OPENAI_API_KEY` = کلید API حساب OpenAI شما
- `OPENAI_MODEL` = مدل موردنظر؛ مقدار پیش‌فرض کد `gpt-5.6-luna` است.
- `RLS_ALLOWED_ORIGIN` = `https://rlsj.ir`

**کلید API را هرگز داخل `admin.js` یا HTML قرار ندهید.**

## 2. اتصال به پنل

بعد از Deploy، آدرس Worker را در:

`https://rlsj.ir/admin/`

در قسمت «سرویس AI» وارد کنید و یک‌بار «ذخیره سرویس» را بزنید. آدرس در مرورگر مدیر ذخیره می‌شود و برای مقاله‌های بعدی لازم نیست دوباره وارد شود.

## 3. گردش کار مقاله

1. اتصال GitHub را انجام دهید.
2. PDF را انتخاب کنید.
3. «استخراج و آماده‌سازی» را بزنید.
4. PDF.js متن چند صفحه اول را استخراج می‌کند.
5. Worker متن را به سرویس AI می‌فرستد.
6. عنوان، چکیده، کلیدواژه‌ها، نویسندگان، وابستگی‌ها و ORCID در سه زبان آماده می‌شوند.
7. شما نام نویسندگان، ORCID و ترجمه‌ها را بررسی می‌کنید.
8. فقط شماره صفحات، نوع مقاله و تاریخ‌های دریافت/پذیرش/انتشار را تکمیل یا اصلاح می‌کنید.
9. سپس «پیش‌نمایش» و در نهایت «انتشار مقاله» را بزنید.

## نکات مهم

- PDF اسکن‌شده که لایه متنی ندارد ممکن است با PDF.js متن قابل استخراج نداشته باشد؛ برای چنین فایل‌هایی OCR لازم است.
- مدل AI نباید ORCID یا اطلاعات کتابشناختی غایب را حدس بزند.
- ترجمه‌های AI قبل از انتشار باید بازبینی شوند.
- DOI همچنان به‌صورت «در انتظار اختصاص» باقی می‌ماند و پنل DOI جعلی تولید نمی‌کند.
