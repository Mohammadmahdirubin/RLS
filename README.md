# Russian Language Studies (RLS)

Official website repository for **Russian Language Studies**, a scholarly journal focused on Russian language, linguistics, literature, culture, translation, and language education.

## Website

This repository contains Version 1 of the journal's static website, prepared for publication with GitHub Pages.

## Important

This is an initial website prototype, not a complete OJS installation. It does not yet provide a database, reviewer accounts, manuscript tracking, or automated peer-review workflow.

Before accepting manuscripts, replace the placeholder:
- editor email
- Google Forms submission URL
- editorial-board information
- ISSN and DOI information, only after they are officially obtained

Do not publish manuscript files or confidential peer-review material in this repository.

## GitHub Pages

Enable **Settings → Pages → Deploy from a branch → main → /(root)** to publish the site.

The official site is available at https://rlsj.ir/ after the custom domain DNS configuration.
